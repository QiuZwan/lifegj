# 生活管家 · Android(Compose)

「上班族 × 个人生活管家」界面设计 V10 的 Android 实现（本机数据版 v2.0）。技术栈：Kotlin + Jetpack Compose + Material 3，按「静护」设计系统（骨白纸面 + 深玉绿）还原设计稿；数据为**用户自己记录、本机持久化、多模块联动**。默认完全离线，只有「桌面天气」与你自己填了接口的「AI 智能管家」会联网。

版本历程：

- v1.2 一键扫描与诚实取消
- v1.3 扣费通知读取
- v1.4 扫描 / 通知自动入清单
- v1.5 旧文案迁移
- v1.6 每日简报提醒、全量编辑与备份恢复
- v1.7 深色模式、家人照片、通知深链、自适应图标与签名发布
- v1.8 可选桌面真实天气（联网仅下载、不上传）、首页速览真实化
- v1.9 记账本与对话记账；**假数据诚实化重构**、档案库可存真实文件、月报、对话发图、系统状态页
- v2.0 **家庭相册独立成册**（与家人头像彻底分开）、**对话升级为 AI 智能管家**（自然语言加订阅 / 家人 / 日期，也能直接问账）
- v2.1 **AI 管家内置 16 家预设（13 家有免费额度，带「去拿 Key」直达申请页）**、**内置备忘录模块**（新建 / 编辑 / 删除 / 分类管理、关键词搜索、按日期排序、单条提醒时间，本机持久化）

## 诚信约定（v1.9 起，v2.0 延续）

这一版把「看起来像真的」全部清掉了。如果你在别处见过相反的说法，以本节为准：

- **不做推算、不编造**。没有记录的地方显示空态，不填假数字。曾经的写死值（`savedTotal = 288`、`closedCount = 3`、写死的「已用 128 天」）已全部删除。
- **统计全部可由列表复算**。已关闭笔数、每月少支出、本月花销、归档文件数，都是由真实列表现算，不是各自维护的独立计数器。
- **首次安装是干净的**。不自动塞演示内容，首页 / 守护 / 档案 / 记账都是真实空态；想看效果需在「我的 → 载入演示数据」显式载入，且演示订阅带「演示」角标，与真实记录区分。
- **扣费记录来自真实来源**。不再按 `nextDate` 倒推伪造「近半年已扣」。扣费流水只有三个来源：短信扫描、通知捕获、你手动补记。
- **不知道就说不知道**。短信 / 通知里没写明扣费日的，不会猜一个日期，而是留空并标「扣费日待补全」。
- **没接 AI 就明说是离线模式**。AI 管家未配置时，对话页顶部直接写「离线规则模式」，不会假装已经接上大模型。
- **AI 只依据本机快照回答**。提示词里明确要求「快照里没有的直说没有」，不猜数字、不编日期、不编商户；模型给出的动作由本机校验后才落库，非法动作直接丢弃。
- **联网去向写清楚**。只有两处会出网：桌面天气（可关闭）、AI 智能管家（你不填接口就完全不启用）。「我的 → 数据与隐私」里如实列出。

## 数据与链路（本机数据版）

- 全部数据保存在本机 SharedPreferences（`lifebutler` / `state_v1`，JSON），重启、杀进程均保留；卸载即清除。
- 记录入口：今日 / 守护 / 时间线 / 家庭 / 档案各页均有「+」；点任务 / 义务可标记完成，长按可删除或编辑。
- 对话可用：接了 AI 就听整句话（加订阅 / 加家人 / 记日子 / 记账 / 问账）；没接 AI 时退化为规则模式，仍支持「记一下：……」「记账：午饭 25」「今天有什么安排」「今天花了多少」「订阅花了多少」「取消 XX」。
- 联动：关闭订阅 → 守护清单「关闭中」+ 我的统计与省下金额；添加订阅 → 今日「替你盯着的」最近一笔；添加义务 → 时间线倒计时 + 今日计数；导出家庭档案 → 生成文本分享。

配置弹窗也跟着改：三个输入框放在最上面（点预设会直接填进去，旁边一行实时显示「当前选的是：xx」），**换服务商时会自动清空 Key 字段**（旧 Key 一定不通用），底部保留「测试连接」与「关闭 AI」。弹窗底部写明：这些平台都要你自己注册领 Key，本应用不代申请、不内置任何共享 Key；免费额度与模型名会随时调整，报错就去「模型名」那一栏改成控制台里写的名字。

> 换句话说：**这个 App 永远不会替你付 AI 的钱，也不会偷偷拿一个共享 Key 去调。** 免费渠道要你自己去注册。

### 备忘录

一个内置的随手记模块，入口在「我的 → 备忘录」，通知点进来也直达这里。

- **新建 / 编辑 / 删除**：右上角「+」新建；点卡片改内容，长按可编辑或删除（删除有二次确认）。标题与内容都是本机纯文本，内容支持换行。
- **分类管理**：默认「工作 / 生活 / 灵感 / 待办 / 未分类」，可随时新增自定义分类；筛选栏右侧「管理」里能查看每个分类的条数并删除分类。**删除分类不会删掉备忘**，它们会改挂到「未分类」。分类与备忘一样写进本机 `SharedPreferences`。
- **关键词搜索**：顶部搜索框同时匹配标题与正文，忽略大小写，边输边筛；点右侧「×」清空。
- **日期排序**：按「最近更新 / 创建时间 / 提醒时间」三种方式排，置顶的备忘永远在最前面。按提醒时间排时，没设提醒的排在最后。
- **置顶**：卡片右上角图钉按钮一键置顶 / 取消。
- **提醒时间**：编辑弹窗里点「提醒时间」→ 快捷行（今天 09:00 / 今天 20:00 / 明天 09:00 / 一周后）+ 日历选择日期 + 时/分步进（分钟 5 分钟一档）。到点由本机闹钟发一条系统通知，点通知直达备忘录页。**每条备忘一个独立闹钟**，改期即覆盖、删除或「清除提醒」即取消；只排将来的时间，所以重启后不会补响一堆过期提醒。已经响过的会显示成「已提醒 M-d HH:mm」。
- **本机持久化**：与其余模块同一份 `state_v1` JSON（`memos` + `memoCats` 两个字段），杀进程、重启都在；备份 / 恢复、清空数据都会把备忘录一起算进去（清空时连同已设的闹钟一并取消）。「我的 → 数据与隐私」的记录总数已包含备忘条数。
- **空态与诚实**：首次安装不塞任何示例备忘；想看效果请在「我的 → 载入演示数据」显式载入（演示数据里会带 4 条备忘，其中一条设了「明天 09:00」的提醒）。
- **权限**：提醒依赖通知权限（Android 13+ 运行时申请）；没授权也能正常记备忘，只是到点不会弹出通知。备忘提醒与「提醒与免打扰」里的每日简报**互相独立**——关掉简报不会影响你自己设的备忘提醒。

## v2.0 新增

### 家庭相册（与家人头像彻底分开）

- **头像是头像**：每位家人的那张脸，点家人卡 →「换一张头像」，存为 `member_<id>.jpg`。
- **相册是相册**：家庭页独立的「家庭相册」区块，与成员数据完全无关。点右上角「+」或空态的「添加照片」按钮，可**一次多选**若干张，每张单独压缩（最长边 1600）后存为 `album_<时间戳>_<随机>.jpg`。
- 相册以三列网格展示（新加的排前面），点开看大图，大图里可删除单张；删档案 / 清空数据时会连带删掉磁盘上的相册文件。
- 为什么改：v1.7~v1.9 的「家人照片」是从 `members` 里筛出「有自选头像的家人」拼出来的，一个人只能有一张，且换头像就会把照片换掉——本质上是把头像当成了相册。现在两者各有各的数据与文件。

### AI 智能管家（可选，自己填接口）

- **入口**：「我的 → AI 智能管家」填 **接口地址 + API Key + 模型名**，点「测试连接」立即验证。三项齐全才生效；留空或清除即回到离线规则模式。
- **内置预设**：v2.0 时是 5 家，v2.1 起扩到 16 家（详见上面 v2.1 一节），点一下自动填好地址与模型名，只需补 Key。
- **协议**：OpenAI 兼容的 `POST {base}/chat/completions`，不引入任何第三方 SDK（`HttpURLConnection` + `org.json`），因此任何兼容该协议的服务都能接。
- **怎么做事的**：一次请求把「本机数据快照」和你的话交给模型，模型返回一个 JSON：`{"reply": "要说的话", "actions": [...]}`。`reply` 显示在对话里，`actions` 由本机逐条校验后真正写进 `ButlerStore`——所以「加订阅」「加家人」「记日子」都会立即出现在对应页面，不是只回你一句「好的」。
- **能执行的动作**：`add_task`、`add_expense`、`add_subscription`、`add_charge`、`close_subscription`、`add_obligation`、`add_member`、`add_key_date`、`add_archive`。模型给出未知动作或非法参数（金额 ≤ 0、名字为空）时直接丢弃，不写入。
- **查询**：快照里包含当天日期、待办、进行中订阅（含合计与下次扣费日）、已关闭笔数与每月少支出、到期事务、家人、关键日期、档案组、相册张数、今日 / 本月 / 近 30 天记账明细与分类合计、真实扣费流水。问账、问订阅、问日程都由模型读快照回答，不问一次写一次。
- **执行回执**：这一句真正写进去的东西，会以「已写进本机」的小卡片单独列在对话流里，和模型的客套话分开，方便核对。
- **失败怎么办**：连不上或模型没按格式回 JSON 时，对话页会如实说「这次没连上模型（原因）」，并**自动用离线规则兜底**处理这一句（能记事就记事，能记账就记账），不会静默失败也不会假装成功。
- **隐私**：Key 只写在本机 `SharedPreferences`（`lifebutler_ai`），**不写入备份文本**，界面上只显示掩码。启用后，你说的话与上述快照会发往你自己填的那个地址；除此之外不发给任何第三方。不填接口 = 完全不联网。

### 顺带的改动

- 本机图片按需解码（`decodeLocal`）：缩略图只解到实际需要的尺寸（相册网格 320、档案缩略 160、对话图 560），不再把整张原图读进内存。
- 系统状态页「本机数据」新增相册张数；备份 / 恢复、清空数据、导出档案的文案与删盘逻辑都已把相册算进去。


### 扣费与扫描

- **一键扫描**：「守护」页 →「一键扫描本机自动续费」。线索来源有三：① 扣费短信（需 `READ_SMS`，仅本机分析）；② 微信 / 支付宝 / 云闪付及常见银行的扣费通知（需开启「通知使用权」，从开启后开始记录）；③ 已安装的常见订阅类应用（`<queries>` 白名单，避免申请全量应用权限）。扫描到的与通知到达的都会自动加入守护清单并标注来源；误加入可移除，移除后不再自动加回。
- **真实扣费流水**（v1.9）：订阅详情页显示该订阅的真实扣费记录，来源标注「扫描 / 通知 / 手动」；可手动补记一笔，长按删除。若你在标记「已关闭」之后仍扫到该商户扣费，会对该订阅打「关闭后仍有扣费」角标。
- **诚实取消**：第三方订阅无法由本应用代取消。「去关闭」提供真实步骤、一键复制、跳转支付宝 / 微信 / 商家 App；点「我已关闭」后标记「关闭中」，月费计入「每月少支出」。

### 新增功能（v1.9）

- **档案库可存真实文件**：「我的 → 家庭档案库」中，每组档案可存照片或文件（支持多选）。照片选完自动压缩后入库，其他文件单份上限 4 MB。卡片显示缩略图与文件数，组内可点开查看（经 FileProvider 只读授权交给系统应用打开，如 PDF 阅读器）、长按移除；删除档案组会连带删除其文件。文件存放在本机 `filesDir`，并纳入备份。
- **月报**：首页「本月月报」卡片与「我的 → 本月月报」进入。显示当月花销（含上月环比、分类占比）、当月扣费流水、在订订阅合计、本月标记关闭与少支出，以及待办 / 义务 / 归档进度。全部由真实列表复算。
- **对话发图**：对话输入框左侧相机按钮从系统相册选图，压缩后存本机并作为消息展示。
- **系统状态页**：展示真实的本机运行状态——数据条数、本机文件占用、权限与开关（短信 / 通知使用权 / 通知 / 位置，可直接跳转申请）、桌面天气上次同步时间与刷新、数据去向说明。
- **备份与恢复**：备份包含头像、家人照片、对话图片与档案文件（有体积上限），恢复前二次确认，恢复后自动重排提醒。

## 运行方式

- 环境：Android Studio（Ladybug 及以上）、JDK 17+；`compileSdk = 35`、`minSdk = 26`、`targetSdk = 35`。Gradle 用仓库自带的 wrapper（9.0-milestone-1），无需另装 Gradle。
- 图形界面：用 Android Studio 打开本目录 → 等待 Gradle Sync → 运行 `app` 配置。
- 命令行：

  ```bash
  ./gradlew assembleDebug     # 调试包
  ./gradlew assembleRelease   # 签名发布包（需先补上密钥文件，见下）
  ```

- `local.properties` 指向本机 SDK 路径，**不入库**；换机器时请自行创建并填入自己的路径。

## 修改指南

- 颜色 / 圆角 / 字体阶梯：`ui/theme/Theme.kt`（token 与设计稿一一对应）。
- 数据层：字段、派生统计、日期计算与对话回复规则均在 `data/ButlerStore.kt`。相册模型是 `ButlerPhoto`（字段 `path` 为绝对路径），与 `ButlerMember.photo`（家人头像）互不相关。
- 备忘录：模型 `ButlerMemo`、分类列表 `memoCategories`、增删改 / 搜索 `searchMemos()` / 排序 `sortedMemos()` / 分类管理都在 `data/ButlerStore.kt`；界面在 `ui/screens/ScreensMemo.kt`（含编辑弹窗与提醒时间选择器）。单条提醒的闹钟与通知集中在 `data/Reminders.kt` 的 `MemoReminders`（排期 / 取消 / 重排）与 `MemoReceiver`（到点发通知）；收件器已在 `AndroidManifest.xml` 声明，开机时随每日简报一起 `rescheduleAll()`。**要改提醒行为，只动这两个对象即可，界面无需改动。**
- AI 管家：`data/AiButler.kt`。上半部分是 `AiConfig`（配置读写 + 掩码），下半部分是 `AiButler`（`ask()` 一次请求拿 reply + actions、`ping()` 测连接、`systemPrompt()` / `snapshot()` 组装提示词与快照、`applyAction()` 校验并落库）。**要加一个可执行动作，只需在 `applyAction()` 里加一个 `case`，并同步写进 `systemPrompt()` 的动作清单。** 配置入口 UI 是 `ScreensLife.kt / AiManagerDialog`。
- 扫描逻辑（短信 / 通知关键词、商户提取、扣费日期解析、应用白名单、线索池）：`data/SubScanner.kt`；通知监听服务：`data/NotifListenerService.kt`；对应权限与 `<queries>`、服务声明在 `AndroidManifest.xml`。
- 档案文件：存于 `filesDir`，对外只读授权走 `res/xml/file_paths.xml` + `AndroidManifest.xml` 里的 FileProvider（authority 为 `${applicationId}.fileprovider`）。
- 本机图片：`decodeLocal(path, maxDim)` 按需下采样解码；`LocalImage` / `LocalPhoto` 是唯一渲染入口，传 `maxDim` 控制缩略图内存。新增图片位要记得传 `maxDim`。
- 图标：`ui/icons/LbIcons.kt`（Tabler 路径内联；增改图标直接编辑 pathData）。
- 演示数据：「我的 → 载入演示数据」触发，实现在 `ButlerStore.loadDemo()`；演示订阅的来源字段标为「演示」，界面显示角标。**不要把演示数据写进 `load()`**，首启必须为空。
- 图片：`res/drawable-nodpi/` 下的 jpg。当前被代码引用的只有这 9 张：`hero_morning / archive_papers / family_home / review_journal / vault_shelf / avatar_mom / avatar_dad / avatar_user / avatar_cat`；同目录下的 `focus_desk / chat_faucet / family_tea / guard_wallet` 暂未被引用（早期版式留下的素材，删掉不影响构建）。
- 应用名：`AndroidManifest.xml` 中 `android:label`；版本号在 `app/build.gradle.kts`（`versionCode` / `versionName`）与 `ScreensLife.kt` 页脚文案两处，改的时候别只改一处。
- 启动图标：自适应图标 `res/drawable/ic_launcher_background.xml / ic_launcher_foreground.xml / ic_launcher_mono.xml` + `res/mipmap-anydpi-v26/`。
- 签名与发布：`keystore.properties` + `keystore/*.jks` 为**自用密钥，不入库**。本地补齐这两个文件后 `assembleRelease` 才会输出已签名包；缺失时 `assembleRelease` 会产出未签名包（`build.gradle.kts` 里对签名配置做了存在性判断）。

## 本地构建的两个坑（Windows + 本仓库）

1. **Gradle 目录被 IDE 锁住**：Android Studio 开着时，`~/.gradle/caches` 里的 `modules-2.lock`、`transforms/*/results.bin` 会被占用，直接跑命令行构建会 `AccessDeniedException`。绕法是给命令行一套独立的 Gradle 目录，同时把官方 cache 以**只读**方式挂进来（只读不抢锁）：
   ```bash
   GRADLE_USER_HOME=<repo>/.gradlehome \
   GRADLE_RO_DEP_CACHE=$HOME/.gradle/caches \
   ./gradlew assembleDebug --max-workers=1
   ```
2. **并发 dex 偶发权限报错**：`mergeExtDexRelease` 在多 worker 下偶发 `AccessDeniedException`。加 `--max-workers=1`，并把 debug / release 分成两条命令分别跑，即可稳定通过。

## 已知限制

- 第三方订阅无法由本应用代取消，本应用只提供步骤与提醒；对 AI 同样如此，它会如实说做不到并帮你记成待办。
- 「通知使用权」只能捕获开启之后到达的通知，开启前的历史通知无法回溯。
- 档案文件单份上限 4 MB（照片会自动压缩，通常不受影响）；相册单张压到最长边 1600。
- `READ_SMS` 属 Google Play 受限权限，本工程定位为自用 / 侧载，未针对上架做合规改造。
- AI 管家需要你自己准备一个 OpenAI 兼容接口的 API Key，费用由该服务商结算；本应用不代付、不转售、不代理。模型偶尔不按 JSON 格式回答时，这一句只会当普通回复显示，不会执行任何写入——宁可不动手，也不乱记。
