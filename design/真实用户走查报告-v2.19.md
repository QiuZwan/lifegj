# 真实用户走查报告（v2.19 · 模拟器）

> 走查方式：`pm clear` 恢复出厂 → 以新用户身份完整走一遍首装引导 → 逐模块体验
> （今日 / 守护 / 智能管家 / 家庭 / 我的 / 搜索 / 帮助），另做深色模式与 2.0× 大字号抽查。
> 全程只用真实用户能用的入口（点按、滑动），仅无障碍树用来定位与检查标注。
> 走查环境：模拟器 Android 14、debug 包、版本 v2.19（versionCode 33）。
>
> 每条问题：**现象 / 复现步骤 / 影响程度 / 改进建议**。

---

## 一、问题清单（按影响程度排序）

### 1.（中）首屏大图卡片上的文字对比度不足

- **现象**：「今日」页与「家庭」页顶部的 HeroCard，白字直接压在浅色照片上。
  「今日」页第一行小字「今天的第一件事」在浅色咖啡图上几乎看不清；
  「家庭」页「给家人的下一件事 / 点下面家人区右上角 + 添加第一位家人」同样发虚。
- **复现**：首装进入今日页（或打开家庭页），直视 HeroCard。
- **影响**：中 —— 这是每页最贵的一块位置，也是引导语所在，看不清等于白写。
  浅色模式明显，深色模式因图片未换同样存在。
- **建议**：给图片加一层由下至上的深色渐变遮罩（或整体压暗 15–25%），
  白字只落在遮罩较深的区域；或干脆把小字标签移出图片、放在卡片上方。

### 2.（中）「今日」页记账后，同屏的月报卡不刷新

- **现象**：在今日页记一笔 ¥25 后，「今天花的钱」立即变成 ¥25，
  但**同一屏**底部的「9 月月报」卡仍显示「花销 ¥0」；切到别的页再回来才变成 ¥25。
- **复现**：今日页 → 「今天花的钱」+ → 金额 25 → 保存 → 不动页面，往下看月报卡。
- **影响**：中 —— 用户刚记完账往下一看月报没算上，第一反应是"没保存成功"，
  会再记一笔，造成重复数据。
- **建议**：让月报卡与「今天花的钱」吃同一个响应式数据源（同一份 store 状态），
  记账后一并重组；顺带检查其他"同屏多卡共用同一数据"的地方是否同病。

### 3.（中）离线模式下，管家认不出自己给出的快捷语示例

- **现象**：断网（AI 连不上）时，点快捷语「帮我加个订阅：网易云 15 块，每月 5 号」发送，
  回复是「先用离线规则处理了：现在还没有订阅记录，在『守护』页右上角可以添加」——
  **没有执行加订阅**，也没说"离线模式加不了"，只给了个答非所问的指引。
- **复现**：断网 → 智能管家 → 点那条快捷语 chip → 发送。
- **影响**：中 —— 这是**引导弹窗第三步教的用法**（「跟管家说一句话」），
  也是快捷语 chip 给出的原文示例；新用户第一句话就碰壁，
  且回复语气像"办好了（只是没记录）"，容易误以为需要去守护页手动加。
- **建议**：二选一：① 给离线规则补这条句式
  （「加个订阅：X N 块，每月 D 号」「帮我加个订阅：…」——示例里用的正是这种自然句式）；
  ② 至少如实回复「离线模式下我加不了订阅，联网后再说一次，或去守护页手动加」。
  同时自查：**快捷语示例是否全部在离线规则的能力范围内**（「记一下」「记账」「订阅一共多少钱」「妈妈生日…」逐条过一遍）。

### 4.（中）2.0× 字号：守护页来源状态条最后一项被截断

- **现象**：系统字号 2.0× 时，四路来源状态条的最后一颗显示成「已装应」，
  「用」字被截掉；且四个均分格已经挤满一行。
- **复现**：设置 → 字号 2.0 → 守护页看状态条。
- **影响**：中 —— 这个条是 v2.19 新加的信任入口，截断让人看不懂最后一项是什么。
- **建议**：沿用底栏 `lbNavLabelSize()` 的思路给圆点文字封顶字号；
  或 2.0× 下把四项改成两行两列；或把「已装应用」这类四字名缩短（「已装」）。

### 5.（中）2.0× 字号：今日页 HeroCard 副标题被截断

- **现象**：2.0× 下「勾掉一件少一件，都完成后我来给你报个平安」只显示到
  「……都完成后我来」，后半句被裁掉，也没有省略号 —— 看起来像话说一半。
- **复现**：字号 2.0 → 今日页（有未完成任务时）。
- **影响**：中 —— 正是"长文本被硬切会像乱码"这个项目明令禁止的问题在图片卡上复现了。
- **建议**：给 HeroCard 的文字区设置 `maxLines` + 省略号，或让卡片高度随字号自适应
  （宁可卡片变高，也不许字被吃掉）。

### 6.（中低）2.0× 字号：顶部日期与问候语折行难看

- **现象**：2.0× 下「9 月 24 日 · 周四」折成「9 月 24」/「日 · 周四」两行，
  与右侧搜索按钮、「本机记录」胶囊挤在一起；「早上好，小满」折成
  「早上」/「好，」/「小满」三行，每行一两个词。
- **复现**：字号 2.0 → 今日页顶部。
- **影响**：中低 —— 不丢信息，但观感明显破损，且是打开 App 的第一眼。
- **建议**：问候语在超大字号下允许整体缩放封顶（如 1.6×）或改单行省略；
  日期行在 2.0× 下把「本机记录」胶囊换行到日期下方，避免三者抢一行。

### 7.（中低）2.0× 字号：守护页 HeroCard 文案折行后孤字成行

- **现象**：2.0× 下「接下来要扣（到下月底）」折成「接下来要扣（到下月」/「底）」，
  右括号孤悬行首；「本月已扣 ¥0 · 在用 0 笔」折成「……在用 0」/「笔」，「笔」字孤行。
- **复现**：字号 2.0 → 守护页。
- **影响**：中低 —— 数字与单位被拆开，读起来别扭。
- **建议**：标签文案在大字号下换短版（「接下来要扣」去掉括号补充，把"到下月底"
  挪进副标题）；或用 `nbsp`/不换行空格把数字与单位绑在一起（「0\u00A0笔」）。

### 8.（中）无障碍：两个图标按钮没有读屏标注

- **现象**：① 智能管家输入框右侧的**发送按钮**（纸飞机图标）无 `content-desc`
  （无障碍树里它是一个空标注的可点击节点；旁边的「发一张图」反而有标注）；
  ② 「今日」页顶部的**搜索按钮**（放大镜）在无障碍树里找不到任何可点击的标注节点。
- **复现**：开启 TalkBack 聚焦到这两个按钮（或 `uiautomator dump` 查看）。
- **影响**：中 —— 读屏用户无法知道这两个按钮是干什么的，而"无障碍"正是这个 App
  自己的卖点之一（代扣协议读取整条线都建立在无障碍之上）。
- **建议**：给发送按钮加 `contentDescription = "发送"`、搜索按钮加 `"搜索"`；
  并全 App 排查一遍 IconButton 是否都有标注。

### 9.（中低）悬浮小管家默认压住页面右侧文字

- **现象**：悬浮小管家默认贴右侧，在「管家帮助」「协议」这类**满宽长文本页**上
  正好压住行尾文字（实测压住了「待确认」「跳去某个页面」「导出一…」「删了…」）。
  2.0× 字号下还压住了「今天要做的事 0/1」的计数。
- **复现**：打开「关于管家 → 管家帮助」，读右侧文字。
- **影响**：中低 —— 可以把它拖走，但默认位置就压字，且每个长文本页都要拖一次。
- **建议**：① 在「帮助 / 协议 / 隐私」这类纯阅读页自动让位（贴到最边缘半透明）；
  ② 或长按小管家临时隐藏；③ 或把帮助页正文的右 padding 让出一个小管家宽度。

### 10.（低）「我的」页「每月省下 —」无解释

- **现象**：三张统计卡里「每月省下」显示「—」，没有说明。
  新用户不知道这是 0、还是"还没法算"。
- **复现**：首装 → 我的页看统计卡。
- **影响**：低 —— 与诚信约定（不编 ¥0、没有记录就不显示）一致，但呈现方式缺一句话。
- **建议**：在「—」下加一行小字「标记关闭第一笔订阅后开始累计」，或点击弹说明。

### 11.（低）搜索结果行「待办」chip 与「未完成」语义重复

- **现象**：搜索结果行右侧挂「待办」分类 chip，行内副文字又是「未完成」。
- **复现**：搜索「Pay」。
- **影响**：低 —— 信息冗余，不影响使用。
- **建议**：结果行只留一个状态表述；分类可以用小字前缀（「待办 · Pay%rent」）。

## 二、走得通、值得保留的部分（同样是走查结论）

- **首装引导三步 + 天气询问**：每一步都把"记录只在本机、不自动加示例"说在前头；
  天气弹窗连"结果缓存 1 小时、随时可在『我的』里关闭"都写了。诚实，不烦人。
- **守护页空态三分法**：首装下明确说「还没开启任何来源，所以这里可能一直是空的」，
  并给出"开一路就行，不用全开"的出路 —— 正确回答了"为什么是空的"。
- **AI 断网的表现**：如实报「这次没连上模型（具体错误）」并声明降级到离线规则，
  没有假装成功（虽然离线规则的覆盖有缺口，见问题 3）。
- **搜索**：两个字触发、跨模块分组、防抖正常，结果与状态一致。
- **深色模式**：即时生效，抽查守护页无对比度塌陷、无残留在浅色的硬编码色。
- **2.0× 底栏**：五个标签不折行、不挤出格子（此前修过的封顶依然生效）。
- **帮助页**：加粗正常渲染、无星号残留，文案已与 v2.19 的能力同步（四条来源、替你点进去）。
